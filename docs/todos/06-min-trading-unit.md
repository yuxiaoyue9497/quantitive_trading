# TODO: 交易最小单位（手）

## 现状
engine.py 中 `position` 列是 0 或 1（全仓或空仓），完全是一个布尔仓位。
没有任何股数/金额级别的精细控制，因此最小交易单位问题被完全忽略。

## A股规则
- **最低买入**：100 股（1 手）
- **卖出**：可以是零股（不足 100 股的部分也允许卖出）
- 买入必须是 100 股的整数倍
- 买入金额 = 股数 × 价格，股数 = n × 100

## 影响
1. **实际可买股数 ≠ 理想股数**：
   - 例：资金 10000 元，股价 47.3 元 → 理想买 211 股 → 实际只能买 200 股
   - 剩余 1540 元无法买入（不足 1 手），变成闲置资金
2. **资金利用率被高估**：回测中 100% 资金都在工作，实际可能只用了 80%
3. **小仓回测偏差**：标的价格低时偏差更大

## 实现建议
1. 当前 model 是"全仓/空仓"，如果要精确模拟：
   ```python
   shares = int(funds / price / 100) * 100  # 取整到 100 的倍数
   position_value = shares * price
   ```
2. 或者在 `strategy_compute()` 中输出精确的 `signal`（不再是 0/1，而是仓位比例）
3. 考虑现金管理：闲置资金产生银行利息（通常 0.01% ~ 0.35% 年利率）
