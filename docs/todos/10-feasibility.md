## 建议优先级排序

1. **最低佣金 5 元** → 简单但影响小额交易
2. **数据质量 & 退市检测** → 基础保障，其他改进都依赖数据正确
3. **涨跌停** → 极端行情下回测的关键修正
4. **停牌** → 与涨跌停配合，处理不可交易状态
5. **T+1 规则** → 需要较大的回测引擎改造
6. **滑点** → 影响高频/中小盘回测结果
7. **最小交易单位** → 需要仓位模型升级为股数级
8. **除权除息** → 需要确认当前前复权数据的安全性
9. **仓位管理** → 属于组合级功能，后续迭代
10. **综合改进** → 在以上基础之上，统一修正所有偏置

## 建议架构改进
当前纯向量计算（pandas apply）无法处理状态依赖（T+1、停牌等），
建议：
1. **短期**：向量化 + 逐行 apply（保留向量化特性，增加条件判断）
2. **长期**：事件驱动回测引擎（更真实，支持复杂场景）
   ```python
   # 事件驱动模式
   for date in trading_days:
       positions = update_signals(positions, signals[date])
       for position in positions:
           execute_trade(position, today_trading_rules)
   ```
