# TODO: 仓位管理

## 现状
engine.py 中 `position` 列是 0 或 1：要么全仓，要么空仓。
没有部分仓位、多目标分散、或现金管理。

## A股交易现实
1. **单一股票仓位限制**：
   - 个人投资者：通常不会一只股票满仓（风险集中）
   - 机构：有严格单一股票限制（如不超过组合 10%~20%）
2. **部分仓位**：信号触发时不一定全仓买入
3. **资金不足**：小额资金可能买不起任何股票（100 股 × 高价股 > 可用资金）
4. **现金管理**：
   - 未投资的现金产生利息
   - 可用资金 = 总资产 - 股票市值
5. **多标的分散**：
   - 当多只股票同时发出买入信号时，如何分配资金？
   - 等权分配？按市值加权？按信号强度加权？

## 影响
当前全仓模型的问题：
1. **过度自信**：每次信号都满仓，现实中你会有犹豫和分批建仓
2. **无分散**：只回测单标的，未测试多标的同时信号的场景
3. **无现金管理**：未考虑闲置现金的利息
4. **无风险预算**：未设置最大回撤限制触发清仓
