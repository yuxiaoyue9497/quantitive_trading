# TODO: 停牌处理

## 现状
当前代码对停牌股票完全没有处理。如果停牌日数据缺失，信号可能延续或误判。

## A股现实
- 股票可能因重大事项（重组、并购、财报等问题）停牌数日甚至数月
- 复牌后可能出现 **跳空高开/低开**（±10% 以上）
- 复牌首日可能继续涨停/跌停（封死无法交易）

## 影响
1. **停牌期间数据为空**：如果均线计算时遇到停牌缺失值，会 NaN 污染后续所有均线值
2. **假信号**：复牌后均线因停牌期间的 "缺失" 而失真，产生虚假的金叉/死叉
3. **复牌跳空**：复牌后可能直接涨跌停，无法执行之前持仓中的卖出/买入
4. **长期停牌后复牌**：市场可能已变化，但策略仍基于旧均线体系运作

## 实现建议
1. 检测停牌：Baostock 的 `tradestatus` 字段中停牌为 2
2. **停牌期间不产生任何交易**：忽略 signal → 持仓保持不变
3. **停牌数据不参与均线计算**：停牌日前收盘价用实际前收盘价，均线用停牌前的
4. **复牌首日**：检查是否仍受涨跌停限制，若受限则不交易
5. 在回测中记录停牌信息到日志

## 优先级
🟡 中高 — 个股停牌概率低但事件影响大

## 涉及文件
- backtest/datafeed/baostock.py（tradestatus 字段已有停牌标识）
- backtest/engine.py（增加停牌日跳过逻辑）
- backtest/strategy/（均线计算时需跳过停牌日）
