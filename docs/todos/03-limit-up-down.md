# TODO: 涨跌停限制

## 现状
engine.py 完全无视涨跌停板，任何信号触发后直接以收盘价/开盘价执行交易。

## A股规则
- **主板（沪深）**：涨跌幅限制为 **±10%**（ST 为 ±5%）
- **科创板（688）**：**±20%**
- **创业板（300）**：**±20%**
- **北交所（8XX）**：**±30%**

涨跌停时：
- **涨停**：买单排在前，但卖方极少 → **买不进去**（排队买不到）
- **跌停**：卖单排在前，买方极少 → **卖不出来**（想卖卖不掉）
- 涨停/跌停板会 **封板多日**，期间持续无法交易

## 影响
最严重的偏置之一：
1. **涨停无法买入**：信号触发涨停日该买入，但实际无法成交 → 模型高估买入信号
2. **跌停无法卖出**：信号触发跌停日该卖出，但实际无法卖出 → 模型高估止损成功
3. **连续跌停**：暴跌行情中可能连续数日无法卖出，造成实际巨额亏损，但回测无感知
4. **涨停开盘**：涨停开盘的股票次日可能高开，但回测无法捕获

## 实现建议
1. 在数据源中获取 `tradestatus` 字段（Baostock 返回中有此字段）
2. 检测涨跌停：当前价 >= 前收 × 1.1（主板） / 1.2（科创/创业） = 涨停
3. 交易执行时增加条件：
   ```
   if price >= limit_up AND action == "buy":  # 涨停，无法买入 → 跳过
   if price <= limit_down AND action == "sell":  # 跌停，无法卖出 → 跳过
   ```
4. 对于 ST 股，涨跌停比例改为 ±5%
5. 科创板/创业板需区分代码前缀（688 开头科创、300 开头创业）

## 优先级
🔴 高 — 在极端行情下回测完全失真
