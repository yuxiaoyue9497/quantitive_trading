# TODO: T+1 交收规则

## 现状
当前 engine.py 中 `position` 列用 `signal.shift(1)` 实现（第 22 行），
即"今天根据昨天的信号决定今天持仓"。如果 signal 从 0 变 1（买入），
今天全仓；下一秒 signal 从 1 变 0（卖出），今天就可以卖出。
这在回测中等价于 **T+0 回转交易**——买入和卖出可以在同一天完成。

## A股规则
A 股严格执行 **T+1**：当日买入的股票，**最少次日（T+1）才能卖出**。

## 影响
- 在高频信号场景下，模型可以一天内反复买卖，赚取不存在的日内价差
- 回测收益会被严重高估
- 真实场景中：你今天买入，最早明天才能卖

## 实现建议
1. 在 engine 中引入 `can_sell` 标志列，买入日标记为不可卖
2. 或者在回测中强制：`is_sell` 仅在 `position.shift(1) == 1`（昨天已持仓）时有效
3. 修改逻辑：signal_change == -1 且之前已持有一日以上 才允许执行

## 优先级
🔴 高 — 直接影响信号逻辑正确性
