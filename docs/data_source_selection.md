# A股行情数据源技术选型记录

## 背景
本项目（A股量化回测框架）最初依赖 `akshare` 获取历史 K 线数据，但在实际使用和替换过程中，经过多轮技术评估，最终确定了当前方案。

## 探索历程

### 第一版: AkShare (初始方案)
- **状态**: 已移除
- **优点**: 开源免费、无需注册 Token、覆盖全 A 股及指数数据、社区活跃。
- **缺点**:
  - 底层依赖新浪/东方财富的爬虫接口，接口频繁变动导致版本兼容性差，经常需要更新库。
  - 无代理/网络异常时失败率高。
  - 历史数据拉取速度较慢。
- **最终去向**: 被替换为更稳定的方案。

### 第二版: Efinance (备选方案 1)
- **状态**: 已替换
- **优点**: 轻量级、纯 Python 实现、底层直接连接东方财富 API、无 Token 限制。
- **缺点**:
  - API 命名不规范（如 `get_quote_history`），参数命名逻辑（如 `fqt=1` 代表前复权）不够直观。
  - 文档较少，部分接口依赖底层非公开接口，长期稳定性存疑。
  - 项目本身活跃度逐渐下降，维护频次降低。
- **最终去向**: 因稳定性和社区维护风险被替换。

### 第三版: Tushare Pro (备选方案 2)
- **状态**: 已替换
- **优点**: 接口高度标准化、数据清洗质量高、支持高频/复权/除权等进阶功能、社区庞大。
- **缺点**:
  - 需要注册 Token，且调用频率/历史接口受积分限制（免费用户每日仅可调用有限次数）。
  - 历史深度数据需要更高积分或兑换才能获得，对普通用户不友好。
  - 接口调用有严格速率限制，批量拉取大量历史数据时需要做复杂的排队/限速处理。
- **最终去向**: 因免费额度受限（积分门槛）及调用频率限制被替换。

### 第四版: Baostock (当前方案)
- **状态**: 当前推荐
- **优点**:
  - **完全免费且无 API Token 门槛**，开箱即用。
  - 接口简单，直接 `bs.login()` 即可获取数据。
  - 提供 A 股、证券、基金、期货、指数等多品种日 K/分钟 K 历史数据。
  - 返回格式为标准 `pandas.DataFrame`，便于直接接入回测引擎。
- **缺点**:
  - 数据粒度较粗（最大支持 5 分钟 K 线），不支持 Tick 级数据。
  - 接口设计较老派，返回数据质量需稍微清洗（如日期格式、停牌日填充）。
  - 接口响应稍慢（底层也是爬取东方财富等源并做缓存）。
- **选择理由**: 平衡了零门槛、稳定性与回测需求，适合个人量化研究及中低频策略回测。

## 总结对比

| 特性 | AkShare | Efinance | Tushare Pro | Baostock |
|:---|:---|:---|:---|:---|
| **费用** | 免费 | 免费 | 免费(基础) + 付费(进阶) | 完全免费 |
| **注册/Token** | 不需要 | 不需要 | 需要 (积分制) | 不需要 |
| **数据质量** | 一般（爬虫源波动） | 较好 | 极好（官方清洗） | 良好 |
| **API 标准** | 尚可 | 一般 | 非常好 | 基础 |
| **数据深度** | 全品种/全周期 | 基础日线 | 深度历史/Tick | 日K/分钟K |
| **适用场景** | 快速探索/通用 | 轻量行情获取 | 机构级/深度研究 | 个人回测/教学 |

## 结论
当前采用 `baostock` 作为默认数据源。若后续需要更高维度的基本面数据或进阶财务指标，可考虑叠加 `Tushare Pro` 的免费基础接口，或基于 `AkShare` 做数据补录。
