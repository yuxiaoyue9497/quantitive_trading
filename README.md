# 量化策略回测框架

A 股量化策略回测框架，以经典的**双均线策略**为示例，展示了数据采集、信号计算、向量化回测、绩效分析和可视化输出的完整流程。

## 功能特性

- **数据获取**：通过 AKShare 自动拉取 A 股历史日 K 线数据
- **双均线策略**：MA5/MA20 金叉买入、死叉卖出的经典策略
- **手续费建模**：买入佣金万三 + 卖出佣金万三 + 印花税千一 + 过户费
- **向量化回测**：高性能 pandas/numpy 向量化计算
- **绩效指标**：总收益率、年化收益率、最大回撤、夏普比率
- **净值曲线对比**：策略净值 vs 基准净值可视化

## 安装

```bash
# 创建虚拟环境并安装依赖
uv sync

# 或直接 pip
pip install -e .
```

## 使用

运行回测：

```bash
uv run main.py
```

## 策略说明

### 双均线策略

- **买入信号**：MA5 上穿 MA20，进入持仓
- **卖出信号**：MA5 下穿 MA20，卖出清仓
- 使用 `shift(1)` 确保信号无未来函数

### 手续费模型

| 费用类型 | 买入 | 卖出 | 说明 |
|---|---|---|---|
| 佣金 | 万三 | 万三 | 不足 5 元按 5 元计 |
| 印花税 | - | 千一 | 仅卖出收取 |
| 过户费 | 万零六 | 万零六 | 沪市收取 |

## 输出

程序输出：
1. 回测绩效报告（收益率、最大回撤、夏普比率）
2. 策略净值与基准净值对比图

## 注意事项

- 当前为简化版回测，未考虑滑点、涨跌停限制、停牌等因素
- MA5/MA20 参数为示例，实际策略需要更深入的参数优化
- 回测结果仅供参考，不构成投资建议
