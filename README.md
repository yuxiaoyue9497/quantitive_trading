# 量化策略回测框架

A 股量化策略回测框架，以经典的**双均线策略**为示例，展示了数据采集、信号计算、向量化回测、绩效分析和可视化输出的完整流程。

## 功能特性

- **数据获取**：通过 AKShare 自动拉取 A 股历史日 K 线数据
- **双均线策略**：MA5/MA20 金叉买入、死叉卖出的经典策略
- **手续费建模**：买入万三佣金+万零六过户费（3.6 BPS），卖出万三佣金+万零六过户费+千一印花税（13.6 BPS）
- **向量化回测**：高性能 pandas/numpy 向量化计算，无未来函数
- **绩效指标**：总收益率、超额收益 (Alpha)、年化收益率、年化波动率、最大回撤、夏普比率
- **手续费统计**：买入/卖出手续费明细、交易次数统计
- **净值曲线对比**：策略净值 vs 基准净值可视化

## 安装

```bash
# 创建虚拟环境并安装依赖
uv sync

# 或直接 pip
pip install -e .
```

## 使用

运行回测：

```bash
uv run main.py
```

## 策略说明

### 双均线策略

- **买入信号**：MA5 上穿 MA20，进入持仓
- **卖出信号**：MA5 下穿 MA20，卖出清仓
- 使用 `shift(1)` 确保信号无未来函数

### 手续费模型

| 费用类型 | 买入 | 卖出 | 说明 |
|---|---|---|---|
| 佣金 | 万三 | 万三 | 不足 5 元按 5 元计（简化版忽略） |
| 印花税 | - | 千一 | 仅卖出收取 |
| 过户费 | 万零六 | 万零六 | A 股双向收取 |
| **合计** | **3.6 BPS** | **13.6 BPS** | 基于仓位价值计算 |

## 注意事项

- 当前为简化版回测，未考虑**滑点**、**涨跌停限制**、**停牌**、**最低佣金 5 元**等因素
- MA5/MA20 参数为示例，实际策略需要**参数扫描**和**样本外验证**
- 手续费按固定费率计算，未随券商差异化调整
- 回测结果仅供参考，不构成投资建议
